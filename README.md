# Main

Vite + React tasks app at the repo root (`npm run dev` → http://localhost:5173).

Standalone games:

- `face-invada/` — FACE INVADA's BEAT BOXING (neon rhythm fighter).
  Play at `/face-invada/` on the Vite server, or `cd face-invada && python3 -m http.server 4174`.
  Sideload the Android APK from the local `downloads.html` page — it is not published on GitHub.
