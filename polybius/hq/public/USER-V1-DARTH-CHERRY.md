## Install

1. Copy the APK to an Android or GrapheneOS device.
2. Open it and allow install from that source.
3. Launch **polybius**.

## Arcade gate

First install creates the built-in operator.

- Operator ID: `DEVELOPER` (uppercase)
- Access key: `developer`

That lands on the neon arcade menu. **START GAME** is the shooter. The gold clock icon opens the clock face.

## Clock

- Clock code (factory): `oneeyedking`
- First successful clock open **requires a new code**. Do not keep the factory code.

### Face

- Analog dial with Roman 24-hour marks **I–XXIV**
- Set **HOUR 05** and **MIN 11**
- Alarm field: `V XIXI`
- Switch **DARTH CHERRY** on (crimson glass)
- Hold **SET ALARM** for **3 seconds**

If those four are not true, the face only says `Alarm saved`.

### Cherry desk

- Typebox for notes
- **MAKE** — hold 2 seconds; typed line clears after 0.8 seconds
- **MAKE QR?** — paste a session key (`PBK-…`) or CREATE one and CUT it
- Hold the **camera cherry** 3 seconds to play a keyboard-only square
- **SCAN KEYBOARD** on the desk, or **SCAN** on the glyph keys, to read that square
- Steg / hieroglyph / sigil set share via QR (NEW SET / SHARE / SCAN)
- **?∞** — tap once, then hold 2 seconds: return to the face and a false **ALARM** banner
- **SLEEP** — two taps: glyph keyboard (`A POLYBĪUS SQU\R3`)
- **STOP** — two taps: exit to the clock code screen
