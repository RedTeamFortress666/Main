# Doomsday Clock journal — Android APK

`doomsday-clock-journal-3.0.0-android-arm64.apk` — Android **arm64-v8a**
release (debug-signed for sideload). Package `com.polybius.doomsday_clock`.

## Install

1. Copy the `.apk` to an ARM64 Android phone.
2. Enable install from unknown sources for the file manager.
3. Open the APK, then launch **Doomsday Clock**.

Camera permission is optional (QR scan). Paste still works without a camera.

This binary is a convenience drop; CI also builds it via
`.github/workflows/release.yml` (`doomsday-clock-journal-android-arm64`).
